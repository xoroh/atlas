# Code of Conduct

The Atlas community follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html). Xoroh's enforcement guidelines are published in the [Xoroh Code of Conduct](https://github.com/xoroh/xoroh/blob/main/CODE_OF_CONDUCT.md) and apply to this repository's issues, pull requests, and project spaces.

Report conduct concerns privately to [conduct@xoroh.org](mailto:conduct@xoroh.org). Reports will be reviewed promptly and handled with respect for the reporter's privacy.

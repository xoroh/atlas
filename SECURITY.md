# Security Policy

## Supported versions

Atlas has not published a release yet. Until then, security reports should target the current `development` branch.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/xoroh/atlas/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

Include the affected commit, impact, and reproduction steps. The maintainers will acknowledge and coordinate reports as promptly as possible; allow time to investigate and prepare a fix before public disclosure.

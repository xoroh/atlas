---
title: Governance
description: How Atlas is maintained and decided.
---

Atlas is maintained by the [Xoroh organization](https://github.com/xoroh).
Issues and pull requests are the public record for proposals, implementation
discussion, and project decisions.

For substantial changes, open an issue before implementation. Maintainers
review contributions for project fit, correctness, security, and
MIT-compatibility. Pull requests target `development`; maintainers decide
when changes are ready for release.

## Standards and provenance

Atlas adopts Xoroh shared standards by reviewed copy; provenance is recorded
in `ADOPTED_STANDARDS.md` at the repository root. The Atlas agent scope and
safety rules live in `AGENTS.md` with procedure in
`.agents/skills/atlas/SKILL.md`.

## Security

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/xoroh/atlas/security/advisories/new).
Never open a public issue for an unpatched vulnerability.

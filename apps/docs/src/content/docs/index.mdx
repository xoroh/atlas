Atlas is the reusable documentation platform for the Xoroh ecosystem. It
powers documentation sites — starting with this one — without absorbing
other projects' documentation identity. Kern keeps its own docs; future
consumers keep theirs.

This site is an early implementation of the platform. Its architecture is
recorded in the [architecture guide](/guides/architecture/).

# Governance

Atlas is maintained by the [Xoroh organization](https://github.com/xoroh). Issues and pull requests are the public record for proposals, implementation discussion, and project decisions.

For substantial changes, open an issue before implementation. Maintainers review contributions for project fit, correctness, security, and MIT-compatibility. Pull requests target `main`; maintainers decide when changes are ready for release.

The product direction is the Atlas documentation engine, recorded in `docs/adr/0003-atlas-core-first.md` (which supersedes the website-centered ADR-0002; the unapproved Astro + Starlight selection in ADR-0001 stays withdrawn). There is no website in this repository — a documentation site is a future consumer project, evaluated only when the engine is ready. Publishing-model decisions (hosting, site URL) belong to that future consumer, not to Atlas Core.
